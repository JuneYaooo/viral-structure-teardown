调研方法：公开网页搜索与产品主页阅读；引用版权归原作者所有，仅作定位说明。
价格锚点中「蝉妈妈 ¥1,398/年、飞瓜 ¥3,998/年、拆解训练营 ¥5,000/人」为需求方
自提供的实测数据（App Store 内购实抓与训练营报价），其余为公开来源。

## 需求证据

- **蝉妈妈「AI拆视频」**：官方 AI 站点把「粘贴爆款视频链接 → AI 拆分镜、爆点台词、
  评论反馈 → 仿写」列为「复刻爆款」工作流核心（[ai.chanmama.com](https://ai.chanmama.com)、
  [chanmama.com](https://www.chanmama.com)），年费档 **¥1,398**（用户提供）。
- **飞瓜数据**：抖音/快手/B站的爆款素材监测与直播分析是会员核心权益
  （[feigua.cn](https://www.feigua.cn)），年费档 **¥3,998**（用户提供）。
- **拆解训练营**：市场上「教你拆爆款」的训练营人均 **¥5,000**（用户提供），人工拆
  一条视频约 0.5–1 小时（知乎多篇拉片经验帖的共识）；新榜「爆拆」栏目自 2021 年
  起每周一篇结构化拆解，连载超百篇——拆解文档本身是被验证的内容形态。
- B站《我拆了100条爆款，70%是这3个结构》2.13 万播放（用户提供）——「少数结构覆盖
  多数爆款」是社区共识叙事，正是模板库的前提。

## 现有方案与差距

| 方案 | 定位 | 与本项目的差异 |
| --- | --- | --- |
| 蝉妈妈 AI拆视频 | 分镜 + 台词 + 评论的付费拆解 | 覆盖画面与数据层，但按年订阅、拆解结果锁定在平台内；本项目只做**文案结构层**，本地运行、拆解卡与模板归用户所有 |

| GitHub 开源（youtubeVideoGenerator 25★、viral-script-generator 3★、scriptforge 3★ 等） | **生成器/爬虫** | 2026-09-19 实测相关项目全部 <50★ 且几乎没有「转写稿→结构标注→模板库」实现，「subtitle srt analysis structure」搜索 0 结果——工具位真空，本项目补的就是这一格 |

## 本项目立场

- **文案结构子集**：蝉妈妈拆画面+数据，本项目只拆转写稿的钩子/留人/转折/转化——
  红线（不打分）反而避开了与数据平台的正面竞争。
- **模板归用户**：拆解卡与模板 JSON 都在本机 templates/ 目录，可自行修改、长期沉淀，
  不锁定在任何平台。
- **结构而非内容**：模板存占比区间与句式功能，不存也不生成整段文案；套用落点时
  必须替换为原创内容。
